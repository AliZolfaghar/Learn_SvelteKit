# درس ۱: شروع یک پروژه خام با SvelteKit

## هدف درس
بعد از این درس، شاگرد می‌تواند با آخرین نسخهٔ پایدار SvelteKit یک پروژهٔ خام بسازد، وابستگی‌ها را نصب کند و سرور توسعه را اجرا کند.

## پیش‌نیاز
- نصب بودن **Node.js** (نسخهٔ LTS پیشنهاد می‌شود)
- آشنایی اولیه با ترمینال (Command Line)
- آشنایی خیلی کوتاه با npm

## قدم ۱: ابزار رسمی ساخت پروژه را بشناس

امروز برای ساخت پروژهٔ جدید SvelteKit از CLI رسمی به نام **`sv`** استفاده می‌کنیم.

دستور اصلی:

```bash
npx sv create my-app
```

توضیح کوتاه:
- `npx` یعنی بسته را بدون نصب دائمی اجرا کن
- `sv create` پروژهٔ جدید می‌سازد
- `my-app` نام پوشهٔ پروژه است (می‌توانی نام دیگری بگذاری)

> نکته: روش قدیمی `npm create svelte@latest` دیگر روش اصلی مستندات نیست. از `npx sv create` استفاده کن.

## قدم ۲: پروژه را با پرسش‌های تعاملی بساز

در ترمینال این دستورها را بزن:

```bash
npx sv create my-app
cd my-app
npm run dev
```

وقتی `sv create` اجرا می‌شود، معمولاً چند سؤال می‌پرسد:

1. **قالب پروژه (template)**  
   برای پروژهٔ خام گزینهٔ **`minimal`** را انتخاب کن.
2. **TypeScript یا JSDoc**  
   اگر تازه‌کاری، می‌توانی با JS شروع کنی؛ اگر آماده‌ای، TypeScript (`ts`) بهتر است.
3. **ابزارهای اضافه** مثل ESLint و Prettier  
   برای شروع خام می‌توانی فعلاً رد کنی.

سپس با `npm run dev` سرور توسعه بالا می‌آید. معمولاً آدرس آن این است:

`http://localhost:5173`

> اگر موقع ساخت، وابستگی‌ها نصب نشدند، قبل از `npm run dev` این را بزن:  
> `npm install`

## قدم ۳: پروژه خام را بدون سؤال زیاد بساز (غیرفعال)

اگر می‌خواهی همه چیز را یک‌جا و بدون پرسش زیاد انجام دهی:

```bash
npx sv create my-app --template minimal --types ts --no-add-ons --install npm
cd my-app
npm run dev
```

معنی فلگ‌ها:

| فلگ | معنی |
|-----|------|
| `--template minimal` | قالب خام و مینیمال |
| `--types ts` | استفاده از TypeScript |
| `--no-add-ons` | بدون ابزارهای اضافه |
| `--install npm` | نصب وابستگی‌ها با npm |

اگر TypeScript نمی‌خواهی:

```bash
npx sv create my-app --template minimal --no-types --no-add-ons --install npm
```

## قدم ۴: اگر می‌خواهی داخل پوشهٔ فعلی بسازی

گاهی پروژه را داخل همان فولدری که هستی می‌سازی (مثلاً همین ریپوی کلاس):

```bash
npx sv create .
```

فقط مراقب باش پوشه خالی یا مناسب باشد؛ در غیر این صورت CLI ممکن است هشدار بدهد.

## قدم ۵: بعد از اجرا چه چیزی می‌بینی؟

وقتی پروژه ساخته شد و `npm run dev` را زدی:
- یک اپ ساده SvelteKit آماده است
- صفحات داخل مسیر `src/routes` تعریف می‌شوند
- اولین بازدید معمولاً Server-Side Render می‌شود و بعد Client-Side App کار را ادامه می‌دهد

در این درس فقط هدف ما «راه‌اندازی پروژه خام» است؛ جزئیات routing را در درس‌های بعدی می‌خوانیم.

## جمع‌بندی
- برای شروع: `npx sv create my-app`
- برای خام بودن: قالب **`minimal`**
- برای اجرا: `cd my-app` سپس `npm run dev`
- آدرس پیش‌فرض توسعه: `http://localhost:5173`
- نسخهٔ پایدار فعلی SvelteKit در پروژه‌های جدید با همین CLI ساخته می‌شود (SvelteKit 3)

## تمرین
1. یک پروژه با نام `hello-sveltekit` و قالب `minimal` بساز و با `npm run dev` اجرا کن.
2. همان کار را یک‌بار با فلگ‌های غیرفعال (`--template minimal --no-add-ons ...`) تکرار کن و تفاوت پرسش‌ها را بنویس.
3. در مرورگر `localhost:5173` را باز کن و بگو اولین صفحه‌ای که می‌بینی مربوط به کدام فایل در `src/routes` است.
